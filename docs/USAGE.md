# 使用说明

憨味米和 Chat GPT 制作。

## 安装与启动

从 [Release](https://github.com/HWMiiii/advanced-quantum-mechanics-notes/releases/latest) 下载完整 App ZIP 与 SHA256SUMS.txt，核对文件大小和 SHA-256 后完整解压。双击 `高等量子力学阅读器.exe`，等待启动校验。无需安装 Obsidian。

不要在压缩包预览窗口内运行；不要只复制 EXE；不要删除同目录的 runtime、DLL、配置、公钥、签名和许可文件。将其放在自己拥有的本地磁盘路径，避免 UNC 网络共享路径。

Windows x64 需要 .NET Framework 4.8 或兼容的 4.8.1；WebView2 固定运行组件已经随包提供，但本包没有附 .NET 安装器。本机实测 Windows 10 22H2；Windows 11 和 ARM64 尚未实机验证。

## 阅读

左侧目录按 8 章 60 节组织。进入一节后，可切换讲解、计算笔记和习题，沿上下节继续阅读。`Ctrl+K` 打开全文搜索，也可以点击搜索按钮；支持按材料类别筛选。

主笔记公式已预排为本地矢量图，补充习题站自带 KaTeX 和字体，不需要联网获取公式服务。图片可放大，长公式和宽表格可横向查看。

上方可调整正文字号和亮暗主题。阅读偏好与最近页面保留在本机；旧补充站中的复习勾选属于临时会话，不保证退出后保留。不会回写你的原始 Obsidian 笔记。

页内引用保留原资料的公式编号和教材页码。整本主教材 PDF 没有随包提供；教材页码入口说明使用第3版中文来源，需读者自备有权使用的对应版本。

## 打印与分享

点击 App 上方或阅读页的打印按钮，也可在阅读区域按 `Ctrl+P`。打印保留制作署名和版本。可正常复制摘录与截图；在分享时请同时保留原著来源。

将完整 ZIP 与校验文件发送给朋友。GitHub 自动生成的 Source code ZIP 只有本仓库说明文件，不是阅读器安装包。

## 校验与退出

启动会检查发行文件签名及资源完整性。点击“版本与校验”或按 `Alt+V` 可重新检查。校验失败时请重新下载完整原版压缩包，不要混用不同版本的 EXE、运行组件或清单。

正常关闭会等待浏览组件退出再清理本次独立会话；失败时保留归属标记以便之后保守重试。不要据此假定系统分页、打印或崩溃转储中绝无痕迹。

公开校验公钥用于版本核验，内容签名不等于 Windows 发布者代码签名。本程序没有受信任的 Windows 发布者证书。

软件问题请提交 [Issue](https://github.com/HWMiiii/advanced-quantum-mechanics-notes/issues/new/choose)，附版本、系统、操作步骤和必要截图；不要公开个人敏感信息。
