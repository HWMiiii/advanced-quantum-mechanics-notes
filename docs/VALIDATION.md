## 学习功能

使用与正式版相同的嵌入内容、桌面阅读代码和随包运行组件，在独立配置下断网连续启动三次。

- 依次打开 171 道补充习题和各题的“本题第一步”，核对 2,309 个解答公式的显示。样例包括习题 1.17 的 2×2 泡利矩阵和习题 8.2 的 4×4 CNOT 矩阵。
- 全文搜索“光源每秒发出的光子数”命中习题 1.3，打开后可阅读新版提示。
- 在长文中途退出并重新打开，续读恢复到之前的位置。自测勾选、撤销勾选均在重启后保留。
- 实际选择第三版中文教材后，§7.3 的引用打开 PDF 第 448 页，对应印刷第 426 页。重启后可再次打开原文件；移除教材关联后再启动，该关联已清除。
- 三次运行均正常退出并清理各自的临时会话。测试期间未捕获页面异常或外部 HTTP 请求。
