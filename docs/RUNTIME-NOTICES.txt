一、随包组件
• Microsoft.Web.WebView2 SDK 1.0.4314.35：Core、WinForms 和 x64 Loader。
• Microsoft Edge WebView2 Fixed Version Runtime 157.0.4341.60 x64：runtime 文件夹中的完整官方运行组件。
• Windows 提供的 .NET Framework 是宿主依赖，并不等同于上述 WebView2 运行时。

SDK 的版权、再分发条件与声明见 WebView2-SDK-LICENSE.txt；第三方通知见 WebView2-SDK-NOTICE.txt，均保留官方原文。固定版运行时适用 WebView2-Runtime-Fixed-Version-License.html 中的微软条款。使用运行组件即适用其条款；本说明不替代完整许可。

二、使用与转交
请将完整阅读器解压到自己拥有的本地文件夹，并从阅读器程序进入。不要只复制 EXE，也不要删除、修改或拆分 runtime 目录及许可文件。运行时不能从 UNC 网络共享路径直接启动。

Windows 10 下，阅读器可能为随包 runtime 目录补充两个 Windows 应用容器组所需的读取/执行权限，以满足微软固定版运行时的要求；操作仅限本阅读器内的运行组件，不申请管理员权限、不修改系统已安装的 Edge/WebView2 或其注册表。若无法设置，请重新解压到自己的本地文件夹。Windows 11 不需要这一步。

阅读器为自己的会话创建独立临时目录；关闭时在运行进程退出后尝试清理。不会使用或删除个人浏览器资料。不能确认归属、仍有相关进程使用或含目录链接的历史会话会保留，不会强行删除。

固定版运行时不会自动更新。本阅读器后续版本可携带更新后的运行组件；请保留整包结构及微软、第三方许可和通知。本组件不应作为独立产品再发行。书页内容的署名及使用边界请参阅阅读器内的“署名与使用说明”；微软组件许可不改变原著与整理内容的权利归属。
