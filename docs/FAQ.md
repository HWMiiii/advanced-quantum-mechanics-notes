# 常见问题

## 为什么现在没有 Obsidian 下载了？

项目已改为发布 Windows 加密离线 App。当前分支中的笔记目录和旧 Obsidian Release 已撤下，本地原资料仍保留。仓库地址不变，下载请前往 Release。

这不等于清除互联网上所有旧资料：Git 历史提交、缓存、他人克隆和已经下载的副本仍可能保留旧版本，无法通过新 App 让其远程失效。

## 需要网络或 Obsidian 吗？

正常阅读、搜索和公式排版都不需要网络，也不需要 Obsidian。WebView2 固定运行组件已附带。主动打开外部参考链接或下载新版需要网络。

## 为什么压缩包接近 490 MB？

压缩包包含完整离线浏览运行组件、学习内容和公式资源，解压后不必再下载 WebView2。只分享 EXE 会缺少必需组件。

## 下载 Source code ZIP 可以运行吗？

不可以。请下载 Release 附件中的 `Advanced-Quantum-Mechanics-Reader-v1.0.1-win-x64.zip`。本仓库只公开说明、截图和校验资料，没有发布 App 构建源码。

## 如何确认下载的是哪个版本？

本次发布标签为 `app-v1.0.1`。在 App 内点击“版本与校验”，可查看程序版本 1.0.1 以及内容修订日期 2026-11-20。

## 公式乱码或资源校验失败怎么办？

先核对 ZIP 的 SHA-256，重新完整解压到新的本地文件夹，确认没有混合不同版本文件。不要删除 runtime、DLL、配置、签名或许可文件。若仍失败，提供 App/系统版本、页名和错误信息。

## 如何打开和保存教材页码？

下载包内附课程讲义。主教材请自行准备页码匹配的《现代量子力学（原书第3版）》中文版 PDF。第一次点击讲义引用时选择文件，阅读器会记住本机文件位置。移动教材后重新选择即可。阅读进度和教材选择仅保存在使用者的电脑上。

## 这是官方教材或完全正确的题解吗？

不是。这是“憨味米和 Chat GPT 制作”的非官方学习整理，含 AI 辅助内容。原有疑点、待核对项和历史快照继续保留；软件验收不能代替数学内容逐题核对，材料齐备也不代表学习者已经掌握。

## 为什么仍可以复制、截图和打印？

正常学习使用保留这些功能。离线加密提高直接拆取、替换和重新打包的成本，无法完全阻止逆向、内存提取、截图或转售。

## 会影响我的 Edge 或 Chrome 资料吗？

App 使用独立会话目录，不修改个人浏览器资料。正常退出等待运行组件释放后清理本次会话；锁定、超时或无法确认归属时保留以便重试。操作系统分页、截图、打印和崩溃转储等仍可能留下数据，不能承诺绝对零磁盘痕迹。

## 为什么有“未知发布者”提示？

本程序未使用受信任的 Windows 发布者证书。内容/发行签名验证的是版本和文件完整性，与 Windows 发布者代码签名不同。请先核对官方仓库地址、Release、文件大小与 SHA-256。
